About This Project

Objective

Compare the architectural performance of CPU versus GPU when running a text-classification workload, focusing on inference latency, throughput, and memory consumption.

Why GPUs Are Usually Faster

Neural-network inference is dominated by large matrix multiplications. GPUs contain thousands of lightweight cores that execute these operations in parallel, while CPUs have fewer, more complex cores. This massive parallelism is the main reason for the observed speed-up.

Current Status

This is the frontend demonstration only. Classification results and performance numbers are simulated. A real model and measurement backend will be integrated later.
